# Intern Apps

A collection of apps built during internship training, using HTML, CSS, and JavaScript.

## Apps

- **Scientific Calculator** — full scientific operations with precedence-aware expression evaluation (no `eval()`), calculation history, and error handling for edge cases (division by zero, negative square roots, invalid factorials).
- **Alarm Clock** — live clock display, multiple alarms with optional repeat days, snooze/dismiss, and audio alert.
- **Snake Game** — classic snake with keyboard/D-pad controls, collision detection, and scoring.
- **Dino Runner** — endless runner with jump mechanics, procedurally spawned obstacles, and increasing difficulty.

All apps are built as installable Progressive Web Apps (PWA) — they can be added to a mobile home screen and opened full-screen like a native app.

Open `index.html` at the root for a landing page linking to all four apps.
